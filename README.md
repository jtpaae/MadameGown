## 🌟 จุดเด่นและฟังก์ชันหลักของเว็บไซต์ (Key Features)

### 1. 🏛️ แบรนด์ & สโลแกนหลัก (Hero & Atelier Heritage)
* สโลแกน: *"Wear Your Success, Cherish Your Journey — ใส่ใจทุกรายละเอียด โดยคุณแม่ช่างใหญ่"*
* ไฮไลท์ประสบการณ์ 15+ ปี, ฮูดซาตินพรีเมียมสีถูกระเบียบ 100%, และแพทเทิร์นเฉพาะตัวสวมใส่สบาย ไม่รั้งคอ

### 2. 👗 แคตตาล็อกสินค้า & ระบบเลือกชุดอัจฉริยะ (Interactive Catalog)
* **การ์ดที่ 1: ชุดครุย พร้อมแถบสี** 
  * เลือกระดับ ปริญญาตรี / ปริญญาโท / ปริญญาเอก โดยภาพจะสลับรูปชุดตามระดับวิทยฐานะอัตโนมัติ
  * เลือกสีประจำคณะ (11 สี มหาวิทยาลัยศรีปทุม - SPU) พร้อมแสดงชื่อคณะและคำนวณราคาเบ็ดเสร็จ
* **การ์ดที่ 2: แถบสีวิทยฐานะ พร้อมโลโก้สถาบัน**
  * มี Close-up Gallery ซูมงานแถบสีจริง ขนขาว 1, 2, 3 ชั้น
* **การ์ดที่ 3: ชุดครุยวิทยฐานะ (อย่างเดียว)**
  * ระบบ **Interactive Vertical Hover-Pan** เลื่อนเมาส์เพื่อดูชุดเต็มความยาว
  * สลับมุมมองได้ 2 แบบ (Dual Photo Switcher): ภาพชุดครุยเต็มตัว (`gown standard.jpg`) และภาพเจาะลึก 5 จุด คอเสื้อ ซิป จีบไหล่ (`gown standard details.jpg`)
* **การ์ดที่ 4: ชุดสูททรงสากลพิธีการ**

### 3. 🎁 ระบบสิทธิพิเศษ & คูปองส่วนลด 3 ใบ (SPU Tiered Promotions)
* **ปุ่มกดเก็บคูปองส่วนลด:** วางเด่นชัดที่มุมขวาบนก่อนเริ่มคอลเลกชันสินค้า เพื่อให้กดเปิดดูและรับสิทธิ์ได้ทันที
* **แถบโปรโมชั่นล่างสุดของคอลเลกชัน:** ข้อความกระชับ *"สั่งซื้อคนเดียวรับส่วนลดทันที 50.- / มาเป็นแก๊งรับส่วนลดสูงสุดคนละ 200.-"*
* **Pop-up แยกคูปองเป็น 3 ใบชัดเจน (3 Voucher Cards):**
  1. `SPU50` — **ส่วนลดก้าวแรก 50 บาท (Welcome Code):** สั่งซื้อคนเดียวรับลดทันที 50.- (จาก 2,000 เหลือ 1,950.-)
  2. `SPUDUO` — **ส่วนลดมาคู่ ลดคนละ 100 บาท:** เมื่อชวนเพื่อนมาจองคู่กัน 2 ท่าน (ประหยัดรวมทั้งคู่ 200.-)
  3. `SPUSQUAD` — **ส่วนลดแก๊งบัณฑิต ลดคนละ 200 บาท:** เมื่อชวนเพื่อนมาจองครบตั้งแต่ 4 ท่านขึ้นไป รับส่วนลดสูงสุดคนละ 200.- (ประหยัดรวม 800+ บาท)
* **กลไกมัดจำสิทธิ์ (Book Now, Add Friends Later):** จองเดี่ยวรับส่วนลดก่อนได้ มีเวลา 48–72 ชม. ชวนเพื่อนมาเปิดออเดอร์เพิ่มในรหัสเดียวกัน ทางร้านจะอัปเกรดคืนเงินส่วนต่างให้เป็น Tier กลุ่มทันที

### 4. 📹 วิดีโอสาธิตการวัดขนาดชุดผ่าน YouTube (Responsive Video Player)
* ฝังวิดีโอ YouTube แบบเต็มจอและปรับขนาดตามหน้าจออัตโนมัติ: [https://youtu.be/3AxMznBzOjw](https://youtu.be/3AxMznBzOjw)
* เครื่องมือคำนวณไซส์ชุดครุยอัตโนมัติจากส่วนสูงหรือความยาวหลังคอถึงกึ่งกลางน่อง
* ตารางเทียบไซส์มาตรฐาน (S, M, L, XL, XXL)

### 5. 🛍️ ปุ่มลอยสั่งตัด/เช่าชุดครุย (Floating Order CTA)
* ปุ่มลอยที่มุมขวาล่างของหน้าจอทุกอุปกรณ์ เพื่อให้ลูกค้าสามารถกดเพื่อเลื่อนมายังจุดสั่งซื้อได้สะดวกตลอดเวลา

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
MadameGown/
├── .github/
│   └── workflows/
│       └── deploy.yml            # CI/CD สั่ง Deploy เว็บไซต์ขึ้น GitHub Pages อัตโนมัติ
├── assets/
│   ├── css/
│   │   └── custom.css            # สไตล์เฉพาะทาง แอนิเมชัน และสีลักชัวรี
│   ├── images/
│   │   ├── gallery/              # ภาพบรรยากาศและผลงานบัณฑิต
│   │   ├── products/             # ภาพชุดครุย, แถบสี 11 คณะ, สูท และภาพเจาะลึก
│   │   ├── logo.jpg              # โลโก้ห้องเสื้อ Madame Gown
│   │   └── measurement_guide.jpg # ภาพประกอบการวัดขนาดชุด
│   └── js/
│       └── main.js               # Logic ระบบคำนวณราคา, คูปอง, Hover-Pan, Modal
├── index.html                    # หน้าหลักของเว็บไซต์ (Single Page Application)
├── .gitignore                    # ละเว้น node_modules และไฟล์สื่อขนาดใหญ่
└── README.md                     # เอกสารแนะนำโปรเจกต์และลิงก์ออนไลน์
```
